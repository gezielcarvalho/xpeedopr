# Project charter

## Purpose

Demonstrate a modern helpdesk domain across a .NET Web API, React customer-facing application, Angular internal portal, and Docker Compose topology.

## Portfolio value

The project showcases breadth across C#, ASP.NET Core, React, Angular, TypeScript, Tailwind, state management, API documentation, and containers. It should be discussed as an integrated learning/demo environment rather than as deployed operational software.

## Current scope

- JWT-based authentication demonstration in the API.
- React ticket interface with routing, local state management, and mock ticket requests.
- Angular backoffice project structure.
- Container build files, Nginx assets, Compose orchestration, and health-check definitions.

## Outside current scope

- A persistent ticket backend and live frontend/API ticket integration.
- Complete backoffice features, role-based authorization, reporting, notifications, or support operations.
- Production security, secrets management, monitoring, CI/CD, and managed deployment.
